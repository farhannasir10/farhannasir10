### 📐 Engineering Principles

- **Decoupled Architecture Over Monoliths** — Separate heavy compute from UI and event loops. Heavy mathematical workloads belong in native C++ threads, keeping frontends fluid at 60 FPS.
- **Deterministic AI Over Stochastic Chaos** — Eliminate LLM hallucination through strict LangGraph state machines, structured JSON outputs, and verified retrieval guardrails.
- **Database Tuning Before Throwing Hardware** — Profile queries with `EXPLAIN ANALYZE`, build covering indexes, and implement tiered Redis caching before scaling instance tiers.
- **Strict Concurrency & Idempotency** — Design every payment lifecycle, WebSocket event, and webhook consumer to be fully idempotent with atomic database constraints.
- **End-to-End Type Safety** — Unified contracts from database schemas (Prisma/PostgreSQL) and backend DTOs (NestJS) down to client-side components (TypeScript/React).
- **Observable Systems With Structured Logging** — Instrument critical API paths and distributed services with tracing, health probes, and structured error metrics.
